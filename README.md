# Household Consumption Expenditure Analysis (India, 2023–2024)

This repository contains the data analysis and visualization study of the **Household Consumption Expenditure Survey (HCES) 2023–2024**, conducted by the **National Statistics Office (NSO), Government of India**.  
The goal of this project is to uncover insights into consumption expenditure patterns across **states, economic categories, and social categories**, enabling a better understanding of disparities and opportunities for targeted socio-economic policies.  

---

## 📌 Project Objectives
- Analyze **state-wise rural vs. urban monthly per capita expenditure (MPCE)**.  
- Compare **food, intoxicant, and non-food expenditure patterns** across states.  
- Study **household distribution** based on MPCE tiers (0–30%, 30–70%, 70–100%).  
- Visualize **state-wise economic categories** and **social categories** for deeper insight.  
- Provide clear, interactive graphs and dashboards to communicate findings.  

---

## 📊 Key Features
- **State-wise MPCE Trends** → Rural vs. Urban comparison.  
- **Category-wise Expenditure** → Food, intoxicants, non-food.  
- **Household Distribution** → Percentile-based household segmentation.  
- **Demographic Insights** → Economic and social category visualizations.  
- **Visualization Assets** → Graphs, charts, and pie-plots for intuitive understanding.
